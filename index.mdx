This guide explains the basic flow for using Metaphysical Studio.

## 1. Sign in or accept your invite

If you were invited to a workspace, open the invitation email and follow the link.

If you already have an account, sign in with your email.

## 2. Open your project

After signing in, go to **Projects**.

A project is where your files, messages, revisions, and production updates are organized.

{/*  space for screen recording of opening a project  */}

## 3. Upload your files

Use the **Assets** area to upload project materials.

Common files include:

- PDF manuals
- Images
- Videos
- 3D files
- CAD files, if supported for your project

{/*  space for screen recording of uploading files  */}

## 4. Send project notes

Use **Messages** to communicate with the team.

Keep feedback, questions, and revision notes inside the project so everything stays organized.

{/*  space for screen recording of sending project notes  */}

## 5. Review the project

When a project is ready for review, open it from the dashboard and check the latest version.

If changes are needed, send a message with clear revision notes.

{/*  space for screen recording of reviewing the project  */}

## 6. Get support

If you cannot access your project, upload a file, or find a message, contact support.
