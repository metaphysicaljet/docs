---
title: "Viewer settings"
description: "Configure appearance, language, and accessibility options in the viewer."
---

The viewer exposes a **Settings** panel that end users can open from the floating toolbar. It controls the visual theme, display language, and text size.

## Accessing settings

Click the settings icon in the floating toolbar to open the **Settings** modal.

## Available settings

### Theme

Toggle between **Dark mode** and **Light mode**. The default theme is dark.

| Value | Description |
|-------|-------------|
| `dark` | Dark glass-morphism background with light text |
| `light` | Light frosted background with dark text |

### Language

Change the display language for all viewer UI text. The following languages are supported:

| Code | Language |
|------|----------|
| `en` | English |
| `es` | Spanish (Español) |
| `fr` | French (Français) |
| `de` | German (Deutsch) |
| `zh` | Chinese (中文) |

The default language is English (`en`).

### Text and icon size

Adjust the size of text and icons in the viewer for accessibility.

| Value | Description |
|-------|-------------|
| `small` | Compact layout |
| `medium` | Default size |
| `large` | Larger text and icons |

## Default settings

The viewer starts with these defaults:

```typescript
{
  theme: "dark",
  language: "en",
  textSize: "medium"
}
```

## Settings persistence

Settings are saved in the browser's local storage and restored on the next visit. Changing the language immediately updates all translatable strings in the viewer UI.

## Other options

The settings panel also includes:

- **Replay Tutorial** — restarts the interactive tutorial overlay that walks users through the viewer controls.
- **Reset Viewer** — resets the viewer state to its initial configuration. This clears any in-progress step navigation and returns the camera to the default position.

## Branding

The colors and fonts used in all viewer UI components (panels, toolbar, step controls, modals) are configured at the project level through the brand configuration. Refer to the [brand configuration guide](/guides/preview-and-deploy) for details on customizing the visual identity of your viewer.
