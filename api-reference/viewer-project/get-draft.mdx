---
title: "Get draft"
description: "Retrieve the current unpublished draft for a viewer project."
---

## Endpoint

```
GET /api/admin/viewer-projects/{companyId}/{productId}?action=draft
```

**Required permission:** `editor`

Returns the current draft snapshot including timeline steps, visibility assignments, tools, parts, and the last frame number. Returns `null` if no draft has been saved yet.

## Path parameters

<ParamField path="companyId" type="string" required>
  The company identifier.
</ParamField>

<ParamField path="productId" type="string" required>
  The product identifier.
</ParamField>

<ResponseField name="revision" type="number">
  The current revision number. Pass this as `expectedRevision` when saving a new draft.
</ResponseField>

<ResponseField name="timelineSteps" type="array">
  Array of timeline step objects. See [timeline steps](/guides/timeline-steps) for field definitions.
</ResponseField>

<ResponseField name="visibilityAssignments" type="array">
  Array of step object visibility assignments.
</ResponseField>

<ResponseField name="tools" type="array">
  Project tools catalog.
</ResponseField>

<ResponseField name="parts" type="array">
  Project parts catalog.
</ResponseField>

<ResponseField name="lastFrame" type="number">
  The final frame number of the model's animation.
</ResponseField>

<ResponseField name="updatedByUserId" type="string | null">
  ID of the user who saved this revision.
</ResponseField>

<ResponseField name="updatedAt" type="string">
  ISO 8601 timestamp of when this draft revision was saved.
</ResponseField>
