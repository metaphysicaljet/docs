# Welcome to Metaphysical Labs

Metaphysical Labs helps you manage 3D manual projects from one simple workspace.

You can use the app to:

- Create and manage projects
- Upload project files and source materials
- Communicate with the production team
- Review project updates
- Request changes
- Track progress until the final manual is ready

## Basic workflow

1. Create or open your project.
2. Upload the files your team needs.
3. Use messages to ask questions or send notes.
4. Review the 3D manual when it is ready.
5. Request revisions if changes are needed.
6. Approve the final version.
