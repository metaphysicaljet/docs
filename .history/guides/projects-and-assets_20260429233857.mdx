# Projects and Assets

Projects keep your work organized.

Each project can include files, messages, revisions, and production updates.

## Projects

Use the **Projects** page to:

- View all of your active projects.
- Filter projects by month, client, or status (e.g., In&nbsp;Progress, Completed, Blocked) using the filter chips at the top of the page.
- Search for a project by name using the search bar.
- Open a project by clicking its card to see details, messages and files.
- Check the status pill on each project card to see whether it’s **In&nbsp;Progress** (blue), **Completed** (green), or **Blocked** (red).

### Creating a new project

To create a new project:

1. On the **Projects** page, click the **New Project** button.  
2. In the **Create Project** modal, enter a descriptive **Project Title**.  
3. Under **Attachments**, optionally attach files that will be part of the initial project:
   - **3D Model** (.glb or similar)  
   - **Image** (e.g., screenshots or reference images)  
   - **PDF manual** (your instruction manual)  
   - **Video** (demonstrations or walkthroughs)  
4. Toggle **Start a project thread** if you want to open a kickoff conversation with your team and client. Write an opening message to describe the project or instructions.  
5. Click **Create Project**. The system will upload your attachments and create the project. After a moment, the new project will appear in your list.

## Assets

Use the **Assets** page to upload and view project files.

Assets are the source materials your production team uses to create or update your 3D manual.

### Navigating the asset library

The asset library shows the total number of assets and counts for each readiness state (**Staged**, **Processing**, **Ready**, **Failed**).  
You can search for assets by name and switch between categories using the tabs: **3D Model**, **Image**, **PDF**, **Video**, and **CAD**.

### Uploading an asset

1. Click **Upload Asset** at the top of the assets page.  
2. In the **Upload Asset** modal, choose the asset type from the tabs (for example, **3D Model**, **Image**, **PDF**, **Video**, or **CAD**).  
3. Click **Choose asset file** and select your file. A preview and file details will appear.  
4. Fill in the **Project Scope** fields:
   - **Company ID** – your company or workspace identifier.  
   - **Product ID** – the product the asset belongs to.  
   - **Entity Type** – select **Project**, **Tool**, or **Part** to associate the asset.  
   - **Entity ID** – the specific ID for the entity.  
5. Click **Upload Asset**. The asset will be staged and processed. When ready, you can open it from the asset library.

### Managing assets

- Each asset card shows its name, file size, last updated time, and a readiness pill (Staged, Processing, Ready, or Failed).  
- Click an asset card to open its details.  
- Use the action menu (three dots) to download the file or update it (if enabled).  
- Use the search bar to find specific assets and the category tabs to filter by asset type.

### Supported file types

Depending on your project, you may be able to upload:

- PDFs  
- Images  
- Videos  
- 3D files  
- CAD files

### Upload tips

Use clear file names when possible.  

For example:

- `assembly-manual.pdf`  
- `product-front-view.png`  
- `installation-video.mp4`  
- `chair-model.glb`  

Clear file names help your team understand what each file is for.

### If an upload fails

Try these steps:

1. Check that the file type is supported.  
2. Make sure the file is not corrupted.  
3. Try uploading the file again.  
4. Contact support if the issue continues.
